# 생명나무 (말씀 묵상 노트)

말씀 묵상·예배 기록 앱. 웹 화면(`www/index.html`)을 Capacitor로 감싼 안드로이드 앱입니다.

## 태블릿/폰에 설치 (무선)
1. 이 저장소의 **Actions** 탭에서 `Android APK` 빌드가 초록색 체크로 끝났는지 확인합니다.
2. **Releases → 최신 APK (latest)** 에서 `saengmyeongnamu-debug.apk` 를 받습니다.
3. 받은 파일을 열어 설치합니다. 처음에는 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.

## 수정 반영
`www/index.html` 을 고쳐 `main` 에 올리면 자동으로 새 APK 가 만들어집니다.

## 참고
- 음성 입력은 안드로이드 자체 음성 인식을 씁니다(마이크 권한 허용 필요).
- 개발용(debug) APK 입니다. Play 스토어 출시에는 서명 키와 릴리스 빌드가 따로 필요합니다.
- 앱 안에서 Claude 에게 묻는 AI 기능과 계정 동기화는 이 앱에서는 동작하지 않습니다.
